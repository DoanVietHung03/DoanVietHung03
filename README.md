## 🚀 Selected Projects

### 📏 Monocular Distance Estimation
A real-time distance estimation system using a **single monocular IP camera**, combining:

- Geometry-based estimation
- Deep learning
- Real-time video processing

Exploring how much useful spatial information can be extracted from a standard camera without relying on expensive depth sensors.

---

### 🧾 Real-Time POS & Cashier Monitoring
A Computer Vision system designed to detect potential cashier fraud in real time.

The pipeline combines:

**Object Detection → Tracking → Temporal Analysis → OCR → Validation → Database**

The project focuses heavily on practical engineering challenges such as:

- Tracking stability
- Frame synchronization
- Temporal aggregation
- OCR confidence filtering
- Event-based database writes
- High-throughput processing

---

### 🚗 Real-Time License Plate Recognition
An end-to-end ALPR pipeline combining:

**YOLO → ByteTrack → OCR → Temporal Aggregation → MySQL**

The system is designed to work with both **offline videos and live streams**, with additional mechanisms for:

- Dropped-frame handling
- Tracking recovery
- Duplicate suppression
- OCR filtering
- Stable plate recognition
- TensorRT / ONNX deployment

---

### 📦 Factory Carton Counting
A real-time surveillance system for industrial environments capable of processing multiple **RTSP camera streams** to detect, track and count cartons moving through a defined region.

Focus areas include:

- Multi-stream processing
- Real-time tracking
- Event-based counting
- Robustness under changing camera conditions

A real-time facial recognition system for automating employee check-in / check-out from security camera feeds.

## 🎯 My Engineering Philosophy

I don't want to stop at:

```text
Train Model → Get Accuracy → Done
```

I'm more interested in:

```text
Camera
   ↓
Data / Preprocessing
   ↓
AI Inference
   ↓
Tracking / Temporal Logic
   ↓
Post-processing
   ↓
Business Logic
   ↓
Database / API
   ↓
Deployment
   ↓
Monitoring & Optimization
```

Because in production, **accuracy is only one part of the problem**.

Latency, synchronization, memory usage, hardware limitations, dropped frames, noisy data, reliability and maintainability matter just as much.
